# AI Agent Prompt Context

**Project:** Asafarim Digital Monorepo
**Structure:** pnpm workspaces with multiple apps
**Root:** c:\repos\asm\asafarim-digital

## Apps
- **portal** - Main app (port 3000) - authentication, user management
- **vionto** - Video rendering app (port 3006) - FFmpeg, TTS, storage
- **content-generator** - AI content generation
- **ops-hub** - Operations dashboard
- **marketing-content** - Marketing content management
- **edumatch** - Education matching platform

## Key Technologies
- **Framework:** Next.js 16 with App Router
- **Database:** PostgreSQL with Prisma ORM
- **Queue:** Redis + BullMQ for async jobs
- **Storage:** DigitalOcean Spaces (S3-compatible)
- **Auth:** Custom JWT with @asafarim/auth package
- **TTS:** OpenAI, ElevenLabs, Azure Speech
- **Video:** FFmpeg for rendering

## Development Environment
- **OS:** Windows 11
- **Runtime:** Node.js 22
- **Package Manager:** pnpm
- **Container:** Docker + Docker Compose
- **Database:** PostgreSQL running in Docker (port 55432)

## Common Constraints
- Windows-specific path handling (use `path.join`, forward slashes in configs)
- Spawn processes need `shell: true` on Windows
- Local storage defaults to local-file mode in dev
- Middleware auth redirects to portal sign-in (port 3000)
- Vionto worker runs on port 3007 for health checks

## Important Files
- `docker-compose.yml` - Service definitions
- `start.ps1` - Dev server launcher
- `apps/*/middleware.ts` - Auth configuration
- `apps/vionto/worker.ts` - Render job processor
- `.env` - Environment variables

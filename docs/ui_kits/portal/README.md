# ASafariM Portal — UI Kit

A pixel-style recreation of the ASafariM marketing portal. Dark surface, translucent navigation, three-pillar capability story, gradient typography. Mocked end-to-end with click-throughs to the contact CTA.

## Files
- `index.html` — main demo (hero → capabilities → case studies → contact)
- `Nav.jsx` — top pill nav with brand, links, breadcrumbs
- `Hero.jsx` — full-bleed hero with gradient headline + dual CTA
- `CapabilityGrid.jsx` — three-pillar tile section
- `CaseStudyRail.jsx` — case-study card row
- `ContactPanel.jsx` — contact / start-a-project form
- `Footer.jsx` — footer with brand mark + columns
- `app.jsx` — assembles + handles routing/state

## Design source
Recreated from `/projects/<asafarim-codebase>` Next.js portal app — typography, colors, gradients pulled from `colors_and_type.css` in this design system.
